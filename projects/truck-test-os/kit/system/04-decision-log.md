### YYYY-MM-DD — One repository for the whole company
- **Decision:** a single repository with one folder per area and a CODEOWNERS file.
- **Why:** everyone syncs one folder and can read everything; ownership is still enforced per folder.

### YYYY-MM-DD — Leads edit through their AI assistant
- **Decision:** area leads never use Git directly; their assistant opens the pull requests.
- **Why:** most leads aren't technical; Git would be friction with no benefit.

### YYYY-MM-DD — Cross-area approval through chat (to be validated)
- **Decision:** changes to another area are approved by its lead in the area's chat channel.
- **Status:** reasonable default; review after the first real cross-area case.
