# Annotated research library · starter kit

A way to keep what you read, watch and listen to from evaporating, and to always know whether an idea is a fact, a model, an opinion or a story.

```
library/
├── Sources/
│   ├── Originals/            ← verbatim, never edited
│   └── SRC-001 - <topic>.md  ← the annotated source
├── Syntheses/                ← only with 3+ independent sources
├── Applications/             ← a decision in a real project
├── source-index.md
├── tensions-log.md           ← append-only
└── PROTOCOL.md               ← for you and for any AI assistant
```

## The rules

1. **A source proves someone said it, not that it's true.**
2. **The original is never edited.** Annotations live in a separate file, so a source can be re-read in two years without your past interpretation baked in.
3. **Every claim gets an ID** (`SRC-003 · A7`) and a type: 📊 data · 🧩 model · 🧭 thesis · 📎 anecdote. IDs are never reused or renumbered.
4. **Critical reading and verification are different steps.** Do both: reading finds weak arguments, verification finds wrong numbers.
5. **Two sources citing the same study are one source.** Check the primary before counting a validation.
6. **Contradictions are the most valuable finding.** Log them with a hypothesis; most come down to different years, markets, definitions or incentives.
7. **Source → synthesis → application.** No synthesis from one source, no decision without a synthesis.
8. **The library informs, it doesn't decide.** When a source changes a decision, the change is written in the project, citing the claim ID.

Start with `PROTOCOL.md`, then copy `templates/source.md` for your first source.
